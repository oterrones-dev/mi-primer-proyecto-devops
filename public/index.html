Tecnologías usadas

Linux

Entorno Ubuntu montado en máquina virtual para practicar como en un laboratorio real.

Docker

Contenerización de la aplicación usando una imagen personalizada y desplegable.

Git & GitHub

Control de versiones, commits, push remoto y repositorio público profesional.

CI/CD

Pipeline automático que construye la imagen y la publica tras cambios en la rama principal.

Estado del proyecto

Aplicación web: desplegada en Render y corriendo en la nube

Repositorio: publicado en GitHub

Automatización: pipeline en verde

Imagen: publicada en Docker Hub

Objetivo

Este proyecto fue creado como parte de una ruta práctica de aprendizaje en DevOps para demostrar un flujo completo: desarrollo → versionado → contenedor → automatización → despliegue.
