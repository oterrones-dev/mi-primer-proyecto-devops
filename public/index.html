Stack actual

Base técnica simple, clara y lista para seguir creciendo.

Backend

  • Node.js + Express
  • Endpoints: /api/visits, /health, /metrics
  • Logs HTTP con morgan

Infraestructura

  • Docker con Node 20 Alpine
  • Deploy en Render
  • Persistencia en Redis

Automatización

  • GitHub Actions
  • Imagen publicada en Docker Hub
  • Pipeline listo para crecer

Arquitectura funcional

Un flujo pequeño, pero real: frontend, API, persistencia y observabilidad.

Frontend

  • HTML estático servido desde /public
  • Consulta datos desde la API con fetch()
  • Muestra visitas, salud y métricas

API

  • /api/visits registra visitas
  • /health valida Redis
  • /metrics expone observabilidad básica

Redis

  • visits:total
  • visits:user:<ip>
  • Persistencia del contador entre despliegues
