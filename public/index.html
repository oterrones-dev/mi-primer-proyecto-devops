Stack actual

Base técnica simple, visible y ya con colmillo.

Backend

  • Node.js + Express
  • Endpoints públicos y protegidos con JWT
  • Logs HTTP con morgan

Infraestructura

  • Docker con Redis y monitoreo local
  • Deploy en Render
  • Persistencia en Redis

Observabilidad

  • Prometheus consume /metrics-prom
  • Métricas de requests, errores y logins
  • Grafana listo para dashboards

Arquitectura funcional

Frontend, autenticación, API, persistencia y observabilidad. Pequeño, sí. Inofensivo, ya no tanto.

Frontend

  • HTML estático servido desde /public
  • JWT guardado en localStorage
  • Consumo de endpoints con fetch()

API

  • /login emite JWT
  • /api/visits, /metrics, /version requieren token
  • /health y /metrics-prom siguen públicas

Redis

  • visits:total
  • visits:user:<username>
  • Persistencia del contador y soporte al flujo autenticado
